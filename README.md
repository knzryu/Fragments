## ■ ゲーム概要

**Fragmentsは、SF世界を舞台とした3Dランゲームです。**

プレイヤーは自動的に前進しながら、障害物を回避し、敵との戦闘を通じて能力を強化していきます。

戦闘や能力選択によってプレイスタイルが変化する、ローグライト要素やハックアンドスラッシュ要素取り入れたゲームを構想しています。

---

## ■ 学習・実装している技術

本プロジェクトでは、以下の技術を学びながら実装しています。

- C++のクラス設計とオブジェクト指向プログラミング
- クラス間の責任分担と依存関係（単一責任の原則などを学びながら設計・改善途中）
- STLの`std::vector`を利用したオブジェクト管理
- 3Dベクトルと座標変換の基礎
- Catmull-Romスプラインによる曲線計算
- AABBによる3D衝突判定
- deltaTimeを利用したフレームレートに依存しない移動処理
- ゲームループと更新・描画処理の分離
- Git / GitHubによるバージョン管理

既存のコードをそのまま組み合わせるのではなく、処理の仕組みや設計理由を理解しながら、自力で実装できることを目標にしています。
